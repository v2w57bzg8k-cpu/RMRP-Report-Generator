# RMRP Report Generator — Web

Адаптивное веб-приложение для iPhone и ПК. Поддерживает загрузку DOCX, заполнение меток,
скачивание результата, отправку файла в Discord через Webhook и редактирование полей.

## Публикация
1. Загрузите содержимое этой папки в GitHub-репозиторий (не ZIP-файл, а сами файлы).
2. На Render выберите New → Web Service и подключите репозиторий.
3. Render распознает `render.yaml`. Добавьте значения переменных:
   - `ADMIN_PIN` — придумайте длинный пароль администратора.
   - `DISCORD_WEBHOOK_URL` — URL Webhook нужного Discord-канала.
4. После Deploy Render выдаст публичную ссылку.

## Шаблон DOCX
В Word вставьте метки в места заполнения:
`{{nickname}}`, `{{organization}}`, `{{current_rank}}`, `{{target_rank}}`,
`{{work_done}}`, `{{evidence}}`, `{{extra}}`.
Метки должны быть цельным текстом, без разрыва на разные стили/фрагменты.

## Редактор полей
Откройте `/admin`, введите `ADMIN_PIN`. Можно менять подписи полей и ключи меток.
При изменении ключа в админке такая же метка должна использоваться в DOCX.

## Безопасность и ограничения
- Webhook хранится только в переменной окружения сервера; никогда не вставляйте его в публичный код.
- Используйте длинный уникальный ADMIN_PIN. Не отправляйте его в чат.
- Бесплатный Render может переводить приложение в сон при бездействии; первый запуск после паузы будет медленнее.
- На бесплатном диске Render данные могут быть непостоянными при перезапуске/повторном деплое. Сохраняйте оригиналы шаблонов у себя.
- Первая версия принимает DOCX. Сложные формы с таблицами/колонтитулами могут требовать настройки меток в самом Word.
